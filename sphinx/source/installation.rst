インストール
============

要件
----

* Python 3.10 以上

pip からのインストール
----------------------

.. code-block:: bash

   pip install clipar

開発版のインストール
--------------------

最新の開発版を使用する場合：

.. code-block:: bash

   git clone https://github.com/yourusername/python-clipar.git
   cd python-clipar
   pip install -e .

依存関係
--------

clipar は以下のパッケージに依存しています：

* argcomplete >= 3.6.2
* typing-extensions >= 4.14.1

これらは自動的にインストールされます。
